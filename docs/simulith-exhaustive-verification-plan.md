# Simulith 전수 화면 기능 검증 계획

## 목표

Simulith Stage 5의 화면 행동 검증을 완료한다. SQLite 시뮬레이션 서버에서 사용자가 화면상 실행할 수 있는 모든 활성 링크·버튼·폼·선택기·필터를 확인하고, 결과 화면·저장 상태·오류 상태를 재조회로 검증한다. 이 검증이 끝나기 전에는 실제 데이터베이스 연결을 완료 조건으로 판정하지 않는다.

## 공통 절차

각 화면마다 다음 순서로 기록한다.

1. 초기 화면과 활성 조작 요소 목록을 Chrome 접근성 트리에서 고정한다.
2. 모든 링크를 클릭해 목적지 URL과 화면 제목을 확인한다.
3. 모든 선택기·필터를 열고 각 옵션을 적용해 결과가 바뀌는지 확인한다.
4. 생성·수정·저장 동작은 정상 입력과 빈 값·형식 오류를 각각 실행한다.
5. 삭제·상태 변경·수납 동작은 결과 메시지와 재조회 결과를 확인한다.
6. 오류 제출 뒤 다른 입력값이 유지되는지 확인한다.
7. 소스 변경이 필요한 경우 Vite HMR 로그와 화면 갱신을 확인한다.
8. 각 항목을 `통과`, `실패`, `차단`, `해당 없음`으로 기록한다.

## 완료 조건

- 활성 조작 요소 목록에 누락이 없고 각 항목에 결과가 있다.
- 정상·실패·빈 상태가 있는 폼은 모두 해당 상태를 확인한다.
- 저장·삭제·상태 변경은 재조회로 반영을 확인한다.
- 역할별 허용 화면과 거부·리다이렉트 결과가 기록된다.
- 현재 SQLite 검증 서버와 기존 MongoDB 경로의 경계가 유지된다.
- `npm run check`, `npm test`, `npm run lint`, `npm run build`가 통과한다.

## 중단 기준

화면 오류, 데이터 유실, 오류 제출 후 입력값 소실, 권한 우회, HMR 미갱신이 발견되면 해당 영역을 실패로 기록하고 원인 수정 후 같은 항목을 재실행한다.
