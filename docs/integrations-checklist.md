# 연동·알림 체크리스트

운영 전에 아래 항목을 순서대로 확인한다. (최소·실행 중심)

## 개발 참고

- 오픈뱅킹 흐름·스텁: [`open-banking-stub.ts`](../src/lib/server/banking/open-banking-stub.ts)

---

## 1. 오픈뱅킹(운영)

### 키·자격

- [ ] 운영용 클라이언트 ID·시크릿·인증서(필요 시) 발급·보관 경로 확정
- [ ] 키 회전 절차·담당·만료 알림 설정
- [ ] 샌드박스 키와 운영 키 분리(환경 변수·설정 스위치)

### 계약·준수

- [ ] 금융사/중계사 계약서·SLA·문의 채널 정리
- [ ] 이용약관·개인정보 처리방침에 오픈뱅킹·결제 관련 문구 반영 여부

### 웹훅

- [ ] 운영 웹훅 URL·TLS·서명 검증(또는 고정 IP 허용) 적용
- [ ] 재전송·지연 시나리오 대응(로그·알림)
- [ ] 웹훅 페이로드 스키마 버전 고정·호환성 정책

### 멱등성

- [ ] 결제·입금확인 등 중복 요청 시 동일 결과 보장(멱등 키·유니크 제약)
- [ ] 웹훅·폴링 이중 처리 방지(상태 머신·락)

### 샌드박스 → 운영 전환

- [ ] 엔드포인트·스코프·한도가 운영 값으로 전환되는 체크리스트
- [ ] 전환 직후 소액·모의 거래로 스모크 테스트
- [ ] 롤백 플랜(운영 장애 시 샌드로 되돌릴 수 없으면 대체 절차 명시)

## 2. 학부모 알림(푸시·이메일)

### 동의

- [ ] 채널별(푸시/이메일/SMS) 수신 동의·철회 UI·API
- [ ] 동의 시점·버전·근거 저장(감사 추적과 연계)

### 템플릿

- [ ] 템플릿 변수·다국어·브랜딩 검수
- [ ] 발송 실패·바운스 처리 정책

### 속도 제한

- [ ] 사용자·학원·전역 단위 rate limit 정의
- [ ] 버스트·쿨다운·우선순위(긴급 vs 일반) 구분

---

## 3. 보안

### 시크릿

- [ ] 시크릿은 코드·레포에 없음(비밀 관리자·환경 변수·암호화 저장)
- [ ] 개발/스테이징/운영 시크릿 분리·최소 권한

### 감사

- [ ] 금융·알림·권한 변경에 대한 감사 로그 필드·보존 기간·접근 통제
- [ ] 운영자 조회·보내기 이벤트 기록
